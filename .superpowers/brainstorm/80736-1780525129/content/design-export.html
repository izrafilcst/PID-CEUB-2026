Design: Export, Testes & Fasamento

Seção 4 de 4 — fechando o loop sim→real. 1 decisão aberta: método de inferência.

⚠ Decisão aberta: como rodar a NN no ESP32-S3?

A — Inferência manual em C++ (recomendado)
Rede é só 14→64→64→3 = 2 matmuls + tanh.
~50 linhas de C++, zero dependências.
Export: PyTorch → extrai pesos → weights.h

+ Determinístico, trivial de verificar
+ Sem framework, ~5KB total
+ Paridade Python↔C++ exata
− Manual se a rede crescer muito
B — TFLite Micro
Pipeline do CLAUDE.md original.
Export: PyTorch → ONNX → TFLite → model_data.h

+ Padrão da indústria, escala p/ redes grandes
+ Quantização int8 pronta
− ~50–100KB de framework
− Pipeline de conversão mais frágil
− Overkill p/ MLP de 5KB

Recomendo A para o MVP: a rede é minúscula, e inferência manual dá paridade exata sim↔real (o teste de correção mais importante). TFLite Micro fica como caminho B se a rede crescer.
