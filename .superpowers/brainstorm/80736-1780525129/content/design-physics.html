Seção 3 de 4 — o modelo físico. 1 decisão aberta no fim (fonte das pistas).

O acoplamento que importa: EDF → Aderência

# Força normal aumenta com downforce do EDF:
N = m·g + F_edf        onde F_edf = (pwm/1023)·F_EDF_MAX

# Força lateral máxima antes de deslizar:
F_lat_max = μ · N

# Em curva rápida, demanda lateral cresce com v²/raio.
# Mais EDF → mais N → mais F_lat_max → menos slip.
# ESSA é a razão de existir do ventilador.

Abordagem: deixar o solver de contato do PyBullet resolver a física — basta alimentar lateralFriction (μ) por superfície e aplicar F_edf como força vertical no CoM via applyExternalForce(). A aderência extra emerge naturalmente do aumento de N. Sem modelo de slip custom.

Domain Randomization — a chave do sim→real

A cada episódio, randomiza os parâmetros físicos. A política aprende a ser robusta à incerteza, então transfere para o robô real sem overfit ao simulador.

Frequências de controle

PyBullet física:  240–1000 Hz (substeps)
PID referência:   roda todo substep (espelha 1 kHz do firmware)
Decisão NN:    ~100 Hz (1 ação a cada N substeps)
# MLP 14→64→64→3 em TFLite Micro ≈ <0.5ms no S3,
# mas 100 Hz de decisão é granularidade saudável p/ o MDP.
