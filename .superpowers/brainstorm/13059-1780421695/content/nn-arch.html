Como a NN se encaixa no controlador?

Três arquiteturas — diferentes tradeoffs entre facilidade de treino e potência. Minha recomendação está marcada.

A ★

Camada de Correção Residual (Recomendado)

O PID roda sempre. A NN monitora sensores + encoders e, quando detecta slip ou linha perdida, injeta um delta de correção na saída do PID + ajusta o EDF.


Fluxo de controle
Sensores → PID → pwm_base
Sensores + Encoders + Inércia → NN → Δpwm_L, Δpwm_R, pwm_EDF
Saída final = pwm_base + Δpwm (só quando slip_detected)

Prós

  • Action space pequeno → treina rápido (PPO converge em ~500k steps)
  • Seguro: PID garante comportamento baseline
  • NN só ativa em condições adversariais
  • Mais fácil de validar e debugar

Contras

  • Precisa definir o trigger de slip (threshold)
  • Teto de performance limitado pelo PID base
B

Adaptação de Ganhos (Gain Scheduling)

O PID ainda executa. A NN ajusta continuamente Kp, Kd e o setpoint de base RPM conforme as condições de pista. EDF também é controlado pela NN.


Fluxo de controle
Sensores + Encoders → NN → Kp, Kd, base_rpm, pwm_EDF
→ PID(Kp, Kd) → pwm_L, pwm_R

Prós

  • NN aprende controle adaptativo (estado da arte em robótica)
  • Generaliza melhor para pistas variadas
  • Action space ainda interpretável

Contras

  • Action space maior (4 dimensões contínuas)
  • Mais difícil de estabilizar o treino
  • ~2–3M steps para convergir
C

Substituição Total do PID

A NN controla diretamente [pwm_L, pwm_R, pwm_EDF]. O PID é removido no modo Offroad. A NN aprende tudo do zero.


Fluxo de controle
Sensores + Encoders + Inércia → NN → pwm_L, pwm_R, pwm_EDF

Prós

  • Máxima liberdade de aprendizado
  • Potencial performance além do PID manual

Contras

  • Sample inefficiente: 10–50M steps
  • Muito difícil de garantir segurança
  • O PID bem tunado que temos é desperdício
  • Requer curriculum learning (pista fácil → difícil)

Minha recomendação: A — Correção Residual. O PID que você já tem é bem tunado para pista limpa. A NN precisa só aprender o que o PID não consegue fazer — recuperação de slip, manutenção de downforce em curvas de alta velocidade. Menor action space = convergência mais rápida = resultado em semanas, não meses.
